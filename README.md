# 🎬 Netflix Data Cleaning & Analysis

## Project Overview
End-to-end data engineering project analyzing 8,800+ Netflix titles.

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Steps Covered
1. Data Loading & Inspection
2. Removing Duplicates
3. Handling Missing Values
4. Feature Engineering
5. Exploratory Data Analysis
6. Data Visualization

## Key Findings
- Netflix has 50/50 split of Movies vs TV Shows
- International Movies is the top genre
- January has the most content added
- 8,795 clean titles after processing# Netflix-Data-Analysis
